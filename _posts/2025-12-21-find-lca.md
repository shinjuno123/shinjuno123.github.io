# Problem

![LeetCodeProblem](/assets/2025-12-21-find-lca.md/leetcode-problem.png)


## How to solve problem
- get small value among p and q
- get large value among p and q
- if root.val is smaller than small, the LCA is on the right side in BST (Binary Search Tree)
- if root.val is larger than large, the LCA is on the left side in BST (Binary Search Tree)
- if root.val is between the small and large, the current node is LCA

## Code
```py
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        small, large = min(p.val, q.val), max(p.val, q.val)

        # 1 case
        # if root.val < small -> move right
        # if large < root.val -> move left
        # if small <= root.val <= large -> we found LCA
        # O(H) O(1)

        while root:
            if root.val < small:
                root = root.right
            elif root.val > large:
                root = root.left
            else:
                return root
```

## Complexity
- Time Complexity: O(Height of BST) -> O(H)
- Space Complexity: O(1)
